# Шаблон локального defect log

> АГЕНТ: ЧИТАЙ ЭТОТ ФАЙЛ ЦЕЛИКОМ. Копируй формат в `runtime/defect-log.md`; сам runtime не публикуется.

Записывай только реальные сбои процедуры. Не копируй содержимое памяти и секреты.

```text
YYYY-MM-DD · шаг · симптом · безопасное состояние · следующее действие
```

Пример с синтетическими данными:

```text
2099-01-02 · apply-lessons dry-run · coverage 0.67 · БД не изменена · исправить план LR2
```
