# Шаблон локального work log

> АГЕНТ: ЧИТАЙ ЭТОТ ФАЙЛ ЦЕЛИКОМ. Копируй формат в `runtime/work-log.md`; сам runtime не публикуется.

Не записывай тексты фактов/уроков, секреты, имена и пути владельца.

```text
YYYY-MM-DD · режим · old-id → new-id · создано N · удалено N · facts preserved N/N
YYYY-MM-DD · ✏️ · demo.old.key → demo.new.key · owner override: yes
```

Для clean run без мутаций строка не нужна.
