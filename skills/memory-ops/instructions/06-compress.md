# Режим 🗜️ Сжатие

> АГЕНТ: ЧИТАЙ ЭТОТ ФАЙЛ ЦЕЛИКОМ. Сжатие удаляет воздух, но не смысл; `source=user` без owner override неизменно.

Когда: одна связная тема содержит повторы/филлер. Если внутри несколько тем, перейти к [split](04-split.md) или [regroup](05-regroup.md).

## Шаги

1. Выписать атомарные факты, identifiers, numbers, paths, flags и remedies.
2. Подтвердить один сюжет. Связная запись 500–1000 символов не обязана сжиматься.
3. Удалить только связки, повтор контекста, филлер и детали, которые восстанавливаются за 30 секунд.
4. Сверить draft с исходником факт за фактом; все значимые токены должны остаться.
5. Показать `N → M chars`, полный draft и source. Для `source=user` отдельно запросить owner override.
6. Backup → `patch-entries.mjs` dry-run → apply. Факт и lesson правятся на месте, чтобы сохранить key/id/project/source/negative.
7. Read-back проверяет точный текст и metadata. Post-probe измеряет, дало ли сжатие реальную экономию.
8. Итог: id/key, N → M, N/N facts, unresolved items; в runtime log только идентификаторы и счётчики.

## Нельзя

- проводить owner rewrite только потому, что текст кажется многословным;
- превращать machine merge в `source=user`, если в источниках не было owner records;
- применять `forget + add` к lesson без причины: это может изменить project/reachability;
- считать меньшую длину доказательством сохранности смысла.

## Gate

- [ ] Один сюжет подтверждён.
- [ ] Facts/tokens выписаны до правки.
- [ ] Draft короче и сохраняет N/N.
- [ ] Владелец увидел полный old → new.
- [ ] Owner override присутствует только после отдельного согласия.
- [ ] Dry-run ничего не записал.
- [ ] Read-back подтвердил metadata и текст.
