# Режим 💀 Очистка

> АГЕНТ: ЧИТАЙ ЭТОТ ФАЙЛ ЦЕЛИКОМ. Ни один кандидат не удаляется без явного подтверждения; `source=user` требует отдельного owner override.

Когда: аудит обнаружил доказанный мусор, stale или duplicate. Итог: [completion report](../reports/report-completion.md).

## Шаги

1. Собрать кандидатов 💀/🕰️/🔁, включая дубли fact ↔ lesson.
2. Для каждого указать evidence: что проверялось, каким инструментом, наблюдение и почему rewrite/merge недостаточны.
3. Проверить `source`. Для owner record предложить безопасную альтернативу и явно пометить необходимость owner override.
4. Показать нумерованный delete list. Формулировать «предлагаю удалить», а не «удаляю».
5. Получить подтверждение по пунктам. Частичное согласие касается только названных пунктов.
6. Сделать backup и dry-run. Dry-run обязан оставить hash БД и набор файлов неизменными.
7. Apply: consolidation rows — после обычного подтверждения; `source=user` — только при отдельном согласии и CLI `--owner-override`.
8. Прочитать строки обратно. `Not found` — проверить, была ли строка уже удалена; не считать автоматическим успехом.
9. Сообщить точный итог, unresolved items и сохранность фактов. Записать ids/counters в runtime log.

## Gate

- [ ] У каждого кандидата есть evidence.
- [ ] Rewrite/merge рассмотрены до delete.
- [ ] Delete list показан владельцу.
- [ ] Частичное подтверждение не расширено.
- [ ] Owner records отделены и без override не тронуты.
- [ ] Backup и dry-run завершены до apply.
- [ ] После apply выполнен read-back.
- [ ] Итог не содержит текстов записей или секретов.
