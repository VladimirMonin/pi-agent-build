# Режим ➕✏️ Новая запись или обновление

> АГЕНТ: ЧИТАЙ ЭТОТ ФАЙЛ ЦЕЛИКОМ. Сохраняй только durable knowledge; обновление owner record требует явного согласия владельца.

Когда: появился полезный для будущих сессий факт/урок либо текущая запись доказанно устарела.

## Fitness filter

Не сохранять:
- одноразовое состояние текущей задачи;
- секреты, персональные данные и имя владельца;
- знание, уже закреплённое в source of truth;
- факт, который проверяется за 30 секунд;
- то, что пользователь запретил помнить.

Сохранять: дорогие gotchas/remedies, устойчивые пути/флаги/пороги/версии, явные durable preferences.

## Шаги

1. Просканировать полный соответствующий store, а не только injection slice.
2. Решить: новая тема; append; stale update; conflict; duplicate.
3. Выбрать key depth/project намеренно:
   - 3+ сегмента — домен, который должен co-expand;
   - 2 сегмента — leaf, прибывает только по своему match;
   - project-scoped — только для реально проектного знания.
4. Сформулировать `[Тема]: [суть/gotcha] — [решение/факт].`
5. Если пользователь прямо сказал «запомни это», запрос всё равно должен пройти safety/fitness filter; secret не сохраняется даже по просьбе.
6. Для обновления показать полный old → new и доказательство устаревания. `source=user` требует отдельного owner override; обычное согласие «обнови память» не считается автоматическим разрешением переписать все owner rows.
7. Fact с тем же key обновляется in place; смена key — create/verify new, delete old last. Lesson предпочтительно редактируется in place с сохранением metadata.
8. Read-back и короткий итог с реальным id/key. Runtime log — только ids/counters.

## Gate

- [ ] Fitness filter пройден.
- [ ] Полный store проверен на duplicate/conflict.
- [ ] Key depth/project выбран по reachability.
- [ ] Формулировка короткая и однотематическая.
- [ ] Secret/personally identifying content отсутствует.
- [ ] Для stale update показан old → new.
- [ ] Owner override получен отдельно либо owner row не изменена.
- [ ] Read-back подтвердил запись и provenance.
