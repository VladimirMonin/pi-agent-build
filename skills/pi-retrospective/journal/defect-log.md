# Defect Log — pi-retrospective

Append-only record of what this skill got wrong, unclear, or awkward during real
runs. Primary evidence for improving the skill.

## What belongs here

- Instructions that misled the run or did not apply to the case.
- Steps that were missing and had to be improvised.
- References that did not resolve or pointed somewhere unhelpful.
- Outputs that were technically acceptable but weaker than intended.
- Cases where the skill fired when it should not have, or stayed silent when it
  should have fired.

## What does not belong here

- Feature requests and preferences — those are conversation.
- Anything about a specific user's private context.
- Speculation about causes. Record what happened; leave diagnosis to the person
  improving the skill.

## Format

```markdown
## YYYY-MM-DD — short label for the run

- **Triggered as expected:** yes / no — one clause
- **Issue:** what was wrong, one or two sentences
- **Tied:** what the run did instead, if anything
- **Impact:** none / minor / significant
- **Suggested fix:** if obvious; otherwise leave blank
```

Keep entries to a few lines. This log is read on every improvement pass, so a long
entry gets skimmed and ignored.

## Growth policy

A mandatory log grows. Keep it useful by keeping it small: entries stay short,
superseded entries collapse to one line, and resolved issues move below.
