# Отчёты разведки обновлений

Папка с датированными отчётами разведки обновлений плагинов сборки. Один отчёт — одна разведка.

| Отчёт | Дата | Объём | Итог одной строкой |
|---|---|---|---|
| [2026-11-11-plugins.md](2026-11-11-plugins.md) | 2026-11-11 | 14 активных пакетов | **взять**: ollama-cloud (срочно), subagents, rpiv-todo, пара goal-x+intercom, и пачку «граф кода» (cbm 2.0.0 + CBM 0.12.1 — наша починка вшита автором, патч снимаем; M, не L); **копить**: mcp-adapter (удаляет наш mcpScript), session-search, serena, ast-grep; **нечего обновлять**: ядро, память, polza, context-inspector |

## Правила папки

- **Формат отчёта** — шаблон в [BUILD.LabUpgrade → «Шаблон отчёта разведки»](../../instructions/BUILD.lab_upgrade.instructions.md): метаинформация (дата, модель/исполнители, список пакетов, summary решений) → решения с причинами → обязательные пометки о глубине анализа (где смотрели код, где только релиз-ноуты/коммиты) → границы честности → следующий шаг.
- **Имя файла** — `YYYY-MM-DD-plugins.md` (или `-<тема>.md`): по имени сразу видно, когда разведка делалась в последний раз. Новая разведка — новый файл.
- **Старые отчёты не переписываются.** Допустимы только датированные приписки (итоги исследователей, повторные проверки). Отчёты — история решений: по ним читается, почему месяц назад мы решили обновлять или не обновлять.
- **Сам протокол разведки** (как собирать данные) — в [BUILD.LabUpgrade → «Разведка обновлений»](../../instructions/BUILD.lab_upgrade.instructions.md).
