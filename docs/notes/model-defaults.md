# Модели по умолчанию — решение от 2026-11-11

Решение владельца: одна пара DeepSeek для обоих профилей, максимальный уровень
размышлений, без вариантов «сборок» под чужих провайдеров. Служебные модели
памяти не трогаем.

## Решение

| Профиль | Провайдер | Модель | Уровень размышлений |
|---|---|---|---|
| Code | `ollama-cloud` | `deepseek-v4-pro:0813` | `xhigh` (уходит провайдеру как `max`) |
| Task | `ollama-cloud` | `deepseek-v4.1-flash:1017` | `xhigh` (уходит провайдеру как `max`) |

Запасной маршрут (документируется, дефолтом не становится): `polza` /
`deepseek/deepseek-v4-pro-0813` и `polza` / `deepseek/deepseek-v4.1-flash-1017`.

**Не менялось (сознательно):** служебная модель консолидации памяти
`polza-memory/deepseek/deepseek-v4.1-flash`, embedding-маршрут памяти, настройки
поиска сессий. Их смена требует пересоздания индексов и грозит тихой деградацией
русского поиска — см. [память](polza-memory.md) и риски
[recon-отчёта](../recon/2026-11-11-plugins.md).

## Почему `:1017`, а не «просто 4.1»

- Страница тегов провайдера (`ollama.com/library/deepseek-v4.1-flash/tags`,
  снимок 2026-11-11): оба имени указывают на **одну и ту же сборку** —
  digest `567966df89fe`. То есть «просто 4.1» не отдаёт старую версию… сегодня.
- Но «просто 4.1» — имя плавающее: при следующем выпуске магазин молча переедет
  на новую сборку. `:1017` — закреплённый снимок от 17 октября: это имя останется
  на этой сборке навсегда. Гарантию даёт только тег.
- **Ловушка, пойманная при проверке:** в `pi --list-models` у `:1017` колонка
  max-out показывает 32 768 — это заглушка плагина (у моделей без измеренного
  предела ставится `32768`, см. `limits.generated.ts`), а не свойство модели.
  Реальные пределы обоих имён одинаковые. Опора на digest, а не на эту колонку.

## Уровни размышлений (из исходников пакетов, не слухи)

- **pi-ollama-cloud:** уровни Pi `off/low/medium/high/xhigh`; `xhigh` уходит в API
  как `reasoning_effort: "max"`. Уровень Pi `max` для этих моделей **не объявлен**
  — Pi его не покажет. Максимум для обеих моделей = `xhigh`.
  - `deepseek-v4-pro:0813` — `high`, `xhigh` (плюс выключение);
  - `deepseek-v4.1-flash:1017` — `low`, `high`, `xhigh` (плюс выключение).
- **pi-polza:** список уровней строится только из опубликованных каталогом
  `supported_efforts`; неизвестное — скрывается, никогда не подменяется молча.
- Практика кампаний: запрошенный `max` на деле может работать как `xhigh` —
  в отчётах указывать фактический уровень отдельно.

## Как менять

`settings.json` профиля: `defaultProvider`, `defaultModel`, `defaultThinkingLevel`
(ключи: `off`/`minimal`/`low`/`medium`/`high`/`xhigh`/`max`; список ограничивает
то, что модель заявляет). Штатно — `/model` и `/thinking` (`Ctrl+S` — уровень по
умолчанию). Повторный Apply installer'а **сохраняет** ваши значения: шаблон их не
перезаписывает (см. [config-schemas](../config-schemas.md)).

## Источники фактов

`pi --list-models` (живой список, 2026-11-11); страница тегов Ollama (digest
`567966df89fe`); исходники `pi-ollama-cloud` (`models.generated.ts`,
`reasoning.generated.ts`, `thinking-levels.ts`, `limits.generated.ts`) и
`pi-polza` (`metadata/thinking-levels.ts`).
