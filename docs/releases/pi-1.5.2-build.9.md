# Pi 1.5.2 build.9 — граф кода: патч снят, пара 2.0.0/0.12.1 принята живьём

Второй срез кампании разведки 2026-11-11: локальная правка графа кода вшита автором и снята, обновлённая пара принята реальными прогонами независимой сессией. Ядро Pi 1.5.2 и Node/npm не менялись.

## Что изменилось

### Патч `pi-cbm-011` — снят (вшит апстримом)

Обе половины нашего фикса (`format:"json"` для семи tools и нормализация таблиц `cols/rows`, `groups[].rows`) вошли в pi-cbm 2.0.0 нативно. Патч убран из сборки: манифест (поле `patch`), notices, `docs/fixes/cbm.md`, `docs/components/code-intelligence.md`, тесты. **Откат сохранён:** `patches/pi-cbm-011/` (immutable store + fail-closed guard) и runtime-backups — откат только парой 1.2.1 × 0.11.x, guard честно отказывает на других версиях.

### Пара графа кода

| Пакет | Было | Стало |
|---|---|---|
| pi-cbm | 1.2.1 | **2.0.0** (новый `cli --json` + stdin, normalize, версионный gate) |
| codebase-memory-mcp (внешний) | 0.11.0 | **0.12.1** (документация/ADR/OpenAPI в графе, CBM Lens, Helm) |

Установлено штатными командами (версии подтверждены обратным считыванием). Полную пере-индексацию проектов после обновления переждали в пробе (image identities).

### Прочее

Тестовая обвязка навыка памяти перенесена на его новые скрипты (13/13). Пины среза №1 в `tests/scripts/run-tests.ps1` обновлены. В `scripts/install.ps1` одна строка приведена к ASCII (PS 5.1 читал файл без BOM как CP866 — 20 parse errors роняли installer-тесты).

## Известные ограничения и наблюдения

1. **Наблюдение (не дефект):** `search_graph` показывает in=3/out=5, а `trace_path` callers=1/callees=0 — у tools разные классы рёбер графа; расхождение ожидаемо, зафиксировано.
2. **Дефекты скриптов навыка pi-memory-ops (D1–D11)** найдены независимыми прогонами, два — класса потери данных (D1 «УДАЛИТЬ»-уроки, D5 обнуление записей). По решению владельца навык не правился; список с воспроизведением передан владельцу (`TEST-memory-ops-port.md`).
3. **NOT TESTED:** поведение `normalize-apply`/`export-lanes` навыка и полная регрессия `check-injector` (нужен bundle плагина) — вне охранного задания пробы.
4. CBM Lens фактически включён персистентно (`ui_enabled=true`); слушает только loopback.
