# Pi 1.5.2 build.11 — семантика кода и поиск: оба обновлены, заплатки перенесены, всё живьём

Финальный срез кампании разведки 2026-11-11: ast-grep, serena и поиск по сессиям обновлены, наши локальные заплатки перенесены на новые версии по правилам патчей, каждый шаг принят реальными прогонами. Ядро Pi 1.5.2 и Node/npm не менялись.

## Известные ограничения и наблюдения

1. Удалены два прежних теста заплаты поиска (`test_embedding_prefixes.py`, `embedding-prefixes.mjs`) — они проверяли машину 1.6.0 (build.3), невозможную в пакете 1.6.1; их заменили актуальные юнит-сьюты.
2. Поведение `exposure:"deferred"` у serena подтверждено прогоном (скрытие редких инструментов), но глубокое влияние на UX виджета не измерялось.
3. Следующий шаг кампании — не требуется: **все срезы разведки 2026-11-11 закрыты** (пакеты, модели, граф кода, MCP, семантика/поиск). Остатки вне срезов: ротация ключа Polza (руками владельца), dev-deps pi-polza, дефекты D1–D11 скриптов навыка (у владельца).
