# Pi 1.5.2 build.10 — MCP-адаптер 7.0.1: codemode вместо mcpScript, оба транспорта приняты живьём

Третий срез кампании разведки 2026-11-11: мост к MCP-серверам обновлён до 7.0.1, приёмка переведена на codemode, наши транспортные заглушки сохранены и проверены живьём по обоим транспортам. Ядро Pi 1.5.2 и Node/npm не менялись.

## Что изменилось

### MCP-адаптер 5.3.2 → 7.0.1 (оба профиля)

- **Приёмка переведена на codemode.** 6.0.0 удалил инструмент `mcpScript` (его работу берёт встроенный codemode Pi) — все проверки, конфиги и примеры переведены с `proxy/direct/mcpScript` на `proxy/direct/codemode`.
- **Мёртвые ключи вычищены:** `scriptMode`, `scriptSkill`, `settings.jev` — на 7.x конфиг с ними грузится с уведомлением.
- **Выигрыш 7.0.1:** имена инструментов >64 символов больше не ломают запросы к OpenAI-совместимым шлюзам (**наш Polza-путь**); старт быстрее; честные ошибки.
- **`ensure-context7.mjs` переведён фактически, а не «по номеру»:** exact-guard обновлён до 7.0.1, все пять внутренних функций адаптера (`setPiMcpConfigEnabled`, `loadMcpConfig`, `writeSharedConfigText`, `parseJsonWithComments`, `isServerDisabled`) **сверены с установленным кодом 7.0.1 — контракт не изменился**.
- Встроенный `builtin:mcp` остаётся выключенным: единственный владелец `/mcp`, а ядро не даёт legacy SSE fallback.

### Наши транспортные заглушки — сохранены и приняты

Compat-мидлвари WVM (`server.py`), заставляющие старый SSE-протокол работать через потоковый транспорт, **не тронуты** (прямое требование владельца). Приёмка — живьём, отдельными кейсами:

| Кейс | Endpoint | Результат |
|---|---|---|
| Legacy SSE | `127.0.0.1:7558/sse` | ✓ реальный вызов `wvm_settings_schema` (схема 51 192 симв.) |
| Streamable HTTP | `127.0.0.1:7558/mcp` | ✓ тот же вызов, тот же результат |
| Совместимость диалектов | SSE → через `/mcp` | ✓ подтверждено: НЕ проходит (детерминированная остановка инициализации) — как и предупреждали доки |
| Context7 через codemode | `https://mcp.context7.com/mcp` | ✓ живая цепочка discovery → resolve-library-id → query-docs (документация useState) |
